A Step by Step Guide To Installing VR CyberDeck

## ❓️ What is VR CyberDeck 
VR CyberDeck is a cross-platform desktop deck for sideloading content to Android devices, wrapped in a neon terminal aesthetic that doesn't feel like a 2014 sideloader. Use it as a pure sideloader out of the box, or add your own server for a browsable library.

## 🖥 INSTALLING

1. Install the build for your OS
2. Plug in your Quest via USB (data-capable cable)
3. Allow USB Debugging on the headset
4. Browse a Library and hit download

**[ LIBRARY ] — optional, only when you add a server**

- > Add your own server under Manage Remotes
- > Want a browsable library instead?
